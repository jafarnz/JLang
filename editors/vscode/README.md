# JLang for VS Code

Syntax highlighting, bracket matching and comment toggling for `.jlang` files.

Install from this folder:

```bash
cd editors/vscode
npx @vscode/vsce package        # creates jlang-0.1.0.vsix
code --install-extension jlang-0.1.0.vsix
```

Or copy this folder to `~/.vscode/extensions/jlang` and restart VS Code.
